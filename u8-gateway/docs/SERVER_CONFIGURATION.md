# 服务器配置页面

## 1. 入口和权限

新 IIS 提供服务器管理页面 `/admin/config`。默认只接受服务器本机回环地址访问；完成首次配置后，查看、测试、保存和密钥轮换均要求管理员密码。普通 H5 用户和 PDA 不得访问。

## 2. 配置项

页面维护：

- 环境名称；业务时区固定为北京时间（UTC+8），不能在配置页修改；
- SQL Server 地址、账套数据库、SQL 用户和密码；
- U8 服务器、账套、年度、子系统、U8 用户和密码；
- U8 单据默认制单人及经过确认的公共参数；
- U8 Gateway 内部调用密钥；
- 操作凭证根目录；
- 测试写入开关、限定数据库和限定账套；
- 队列容量、等待时间和日志级别等受控运行参数。

每种单据自己的模板号、收发类别和业务默认值放入单据配置，不混入一个全局默认值。

## 3. 密码和回显

- SQL 密码、U8 密码和内部 API Key 使用 Windows DPAPI `LocalMachine` 加密后保存。
- 管理员密码保存带随机盐的慢哈希，不保存明文。
- 页面读取配置时只返回 `hasSqlPassword`、`hasU8Password` 等状态，不返回密码密文或明文。
- 密码输入框留空表示保留原值；轮换密钥必须明确操作并记录审计。
- 配置文件、运行数据和日志不得提交 Git。

## 4. 测试操作

页面提供：

- 测试 SQL：只建立连接并执行只读检查；
- 测试 U8：只登录、初始化、读取必要信息并注销；
- 保存并应用：测试通过后保存新修订版本；
- 轮换内部密钥：旧密钥立即失效。

测试按钮不得创建、修改、审核或删除真实 U8 单据。

测试写入默认关闭。只有环境为 `test`，并且当前数据库、当前账套分别与限定值完全一致时，写路由和 U8 运行时两层门禁才允许继续。保存配置时也执行同样校验。单据合同的具体能力开关仍须在 888 验收后逐项开启；总开关不能绕过单据能力开关。

## 5. Windows 账号

服务器 Windows 凭据不保存在配置页面。IIS 使用专用应用池身份访问 U8 COM、配置目录和操作凭证目录。远程部署需要的服务器账号只在明确部署时临时使用，不写入源码、配置文件、操作凭证或日志。
