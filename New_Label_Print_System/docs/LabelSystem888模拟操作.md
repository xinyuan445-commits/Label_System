## 怎么测试

1. 当时从服务器单据打印页查询实际888单据并选择未打印明细，填写数量和包装，选择已发布模板、888模拟打印机，点击打印。原来的默认模板、批改包装、尾数和预览仍可用。已有标签或预约占用会扣除，不能反复为同一额度首打。
2. 当时的存货打印页保留筛选、勾选与核对。只能为尚未被标签或待打印目标覆盖的库存建立标签；已有标签请补打。
3. 当时的标签补打页输入完整Code或唯一SN，查询原打印内容，填写份数后补打。历史标签先选重建模板并核验历史首打；核验保存后刷新可继续使用。补打沿用原Code及纸面数量，余额不变。
4. 在原页面选择“模拟发送方式”：正常、丢发送回执、丢登记响应或三表登记失败一次。方式只影响下一次模拟发送，之后回到正常。
5. 异常时打开当时的打印记录与恢复页，查看原任务，查询任务或恢复原任务登记。丢发送回执可先重启模拟助手，原账本与回执保留；丢登记响应时原任务可能已经完成；三表失败只重试原同步。不要再次首打或清空未知请求。

当前编码规则通过侧栏“编码规则”管理，唯一当前为888开发打印规则/版本ID9；格式`888|料号|批号|首次数量|10位唯一值`。模板统一在原“模板管理 → 发布与正式版本”，设计稿3对应正式模板2/版本2，76.2×50.8mm。模板修改后需重新发布；预览不消耗编码。

服务端Go V2模拟驱动配合真实开发SQL及888三表；本机0.7.0助手保持禁打，页面不需要调用本机真实打印机。18003/9891/9881仅测试888；自动恢复关闭，未操作生产008。本轮整合没有迁移或新建数据库。
