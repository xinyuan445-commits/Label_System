## 打印记录的用途

“打印记录”用于查看首打和补打结果、原标签文件及异常任务；恢复操作只在异常时使用，无需每次打印再人工确认出纸。

| 状态 | 应做的操作 | 防重复原则 |
| --- | --- | --- |
| 已完成 | 查看或进入原补打页面 | 不再次首打 |
| 待发送、未发送 | 按原任务发送或继续 | 未知结果不能当作未发送 |
| 待回执、结果待核对 | 查询本机助手保存的原回执，恢复登记 | 不创建新任务、不自动重发 |
| 追溯登记待恢复 | 重试原追溯登记 | 不再调用助手，不新增正向数量 |

本机助手在输出前保存发送意图，输出后持久保存签名回执。V2包内部仍用副本UUID校验文件身份，保存到用户目录时改用 `单号_行号_条码末段流水号.pdf`；独占创建、不覆盖已有文件。重复查询或重放同一attempt读取原回执。结果未知仍保留核对状态，不能承诺已出纸或自动重发。管理员核对记录接口仍保留，说明本身不等于成功回执。
