正式模板版本、任务、快照、回执事件、零数量流水和旧表同步任务均由现有Business API/017管理，Flask不直接连接标签数据库写库存。原SQLite仅保留设计草稿、素材与所有者引用；不保存另一套正式任务或余额。未新增迁移、未再次执行017。

首打/补打及恢复继续使用已确认合同：数量取单据；正式首打才取号；补打沿用原码和原快照；本地PRINT/REPRINT为零数量；首打只建一次稳定PRINT_TARGET；三表失败只恢复原事件；结果未知查询原任务，相关依赖完成才解锁。
