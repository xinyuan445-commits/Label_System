# 2026-11-06 盘点统一1000码上限

## 规则与实现

盘点扫码、草稿、只读核验、上传每单统一最多1000个唯一完整标签码。同料号、同批号的不同Code各占一条，重复Code仍拒绝，不合并扫码记录以绕过上限；U8按料批/按需货位汇总的原有规则保持。第1001码由现有H5提示“本单最多1000张标签”，保留已扫记录；服务端同样拒绝超限，不截断上传。

原问题是盘点核验已允许1000码，后续通用预提交又按500行拒绝。`DocumentPrepareService.ValidateBasicRequest`现在对盘点复用`InventoryCountRules.MaximumObservations`，其他单据仍按原500行规则。既有扫码/核验/Gateway保存已经支持1000，不改H5或Gateway、不增加接口、迁移、数据表或配置开关，不自动拆成多张盘点单。Gateway旧三表查询单批最多100码的限制保持，1000码分10批查询。
