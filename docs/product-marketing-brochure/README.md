# 产品宣传手册编辑与导出

- `index.html`：正文、中英文文案、目录和实际页面截图引用。
- `styles.css`：网页浏览排版；05的四个业务场景连续展示。
- `print.css`：A4竖版分页、目录页码、页脚及打印隐藏控件。
- `brochure.js`：语言切换、图片放大；打印前展开附录，结束后恢复。
- `content-notes.json`：资料来源、图片口径、复核记录及已验证页码。

## 当前PDF

中文与英文均为18页，位于项目 `output/pdf/`：

- `u8-product-brochure-zh.pdf`
- `u8-product-brochure-en.pdf`

05.1—05.4分别位于第7—10页；功能附录位于第15—18页。PDF目录可以点击跳转。正文和图注提供中英文，实际截图保留原界面语言。

## 修改与重新导出

直接打开 `index.html`，选好中文或英文，再在Chrome中打印并选择“另存为PDF”。使用A4、100%缩放、启用背景图形，关闭浏览器附加的页眉和页脚；手册自身通过CSS生成页码。

中英文分别导出。当前目录数字按已验证的18页排版填写；正文、字体或排版修改后，应重新核对PDF页数及目录中的 `.toc-page`，不要沿用未经验证的页码。每次导出检查四个场景、全部48项附录能力以及截图是否完整。

旧操作版保留在 `../product-brochure/`。
