1. 完成PDA盘点采集/重复提示/断网续扫验收；在888核对真实Update、完整应盘范围及审核/记账行为，再实施原单回填和差异生效。复杂离线资源包等另行后置，见[复核记录](INVENTORY_COUNT_REVIEW.md)。
2. 完成材料退料/部分调拨/部分货位调整→正式打印→再扫码的实机回归，核对U8、新表及旧三表。
3. 逐类完成采购、销售、委外的现场验收及各自兼容边界。
4. 实现新旧余额/位置批量对账与异常任务管理；按执行计划验证测试账套索引，生产索引另行评估。
5. 实体打印机验收后安排008打印迁移与发布；观察对账通过后再实施旧三表停写及权威来源切换。

盘点离线仅保存标准草稿中的完整Code/明确数量，不宣称已经下载全范围标签包；旧表资料联网后台核对。没有用户可见的采集任务。无网冷启动、独立离线许可、设备转交/多PDA分工、托盘、其他离线改账及历史打印审计后置。
