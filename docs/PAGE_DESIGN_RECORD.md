## 2. 业务差异

| 业务 | 保留的差异 |
| --- | --- |
| 材料出库 | 原单/无原单、蓝红字、领料/退料及超领相关字段和确认 |
| 调拨 | 明细调出/调入位置，表头调出/调入部门，关联单审核 |
| 货位调整 | 位置调整及部分移动，不伪造调拨单字段 |
| 采购/销售/委外 | 各自来源类型、数量和批号要求；页面相同不表示所有业务已验收 |
| 盘点 | 原单必选，表头只读；逐码采集实盘默认空；本机任务独立；仅联网核验，不允许ERP上传 |

## 3. 盘点页面设计

- 表头：统一返回/标题；源单按钮进入选单子页。选中后显示日期、仓库、来源账套和行数，底部“采集记录”“下一步”。
- 选单：复用DateField，查询单号和起止日期，选中后底部确认，下载/本机保存完成才返回表头。
- 扫码：简短原单摘要、扫码输入、紧凑采集列表；底栏统计、“原单明细”“联网核验”。本机保存及离线状态简短展示。
- 数量编辑：从已有明细进入全屏层，显示完整Code、核验资料和实盘输入，保存/移除；未保存返回需确认。编辑和确认期间暂停扫码。
- 原单明细：单独查看账面和已匹配采集量，不能当作整行最终实盘；返回恢复扫码页。
- 采集记录：独立本机任务列表，选择后恢复任务并进入扫码页；返回恢复进入前页面。
- 以上子页使用同一路由内状态切换；页面按钮/PDA返回逐层关闭，浏览器路由离开检查未保存输入。不新增服务端草稿、迁移或上传流程。
