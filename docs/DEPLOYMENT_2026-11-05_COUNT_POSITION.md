# 2026-11-05 盘点按本次仓库货位同步标签

## 业务规则

盘点扫码不再要求标签原仓库/货位与本单一致。有原单使用原单仓库，无原单使用制单表头仓库。目标仓库启用货位管理时，在共用数量确认页选择有效“盘点货位”；原单盘货位时，可选位置来自同料号/批号的原单行。跨仓不猜目标货位；不管理货位则清空目标货位。

扫码和草稿不改标签。ERP保存确认后，旧三表与本地镜像的余额按实盘同步，当前位置按本次确认目标更新；未扫标签保持不变。系统仅保存当前U8盘点单，不自动生成原仓库的出库/调拨；原仓库ERP库存由用户处理。

## 实现

- 前端复用现有数量确认和SearchSelect，分别保存原快照与目标位置；旧草稿跨仓时不沿用原货位。离线续扫仍保存普通草稿，联网必须复核。
- 两个核验接口的observations增加可选targetLocationCode；原单匹配不比较标签原位置，按本次目标匹配。上传来源字段保留原快照，目标仓库强制取本单表头。
- U8写入前仍实时核对原最新流水ID、余额和位置，另校验目标仓库及货位归属；U8实盘和历史贡献按目标仓库/按需货位累计。
- 同一COUNT_ADJUSTMENT事件保存数量差异及目标位置，零差异也可更新位置。旧Goods根/inventory位置及既有优先别名同步更新；Order仓库取本次表头。稳定事件、锁及失败恢复保持。
- 本地inventory_flow记录原位置→目标位置及盘前/差异/盘后数量。沿用019、通用业务明细/操作事件/同步任务，无新增表、迁移或开关。
- 材料出库、调拨及货位调整的原有位置规则不改。已完成操作159不追溯重写。
