## 1. 功能说明

处理生产领料和红字退料，入口为材料出库单。使用共用的表头、扫码、明细确认和单据管理页面。

## 3. 操作流程

选择蓝字或红字及可选生产订单 → 填表头 → 下一步 → 扫标签或选择无标签退料物料 → 确认数量/必要位置 → 完成做单保存草稿 → 单据管理上传 → 按设置自动或手工审核。拆单时保存各张ERP返回单号。

## 4. 规则与限制

- 标签当前余额来自旧三表，不使用Code打印数量；异常标签、锁冲突、最新版本/位置不符不得直接继续。
- 蓝字与红字不同：有原单红字按所选需求行当前可退量限制，不套用蓝字超领规则；无标签退料不伪造原标签余额。
- 原标签退料输入正数，由服务端转换为红字业务；退料位置可按规则修改。业务明确成功前不提前恢复标签余额。
- 无标签退料的目标标签先无Code，实际首打才分配正式Code；打印前不得使用空码/临时码写旧三表。
- ERP结果未知先核对；ERP成功但旧表同步失败沿原事件恢复，不能直接再新增ERP单据。
- 本阶段不把托盘作为已验收业务；不承诺离线扫码领料或离线写ERP。功能权限、类别范围、ERP映射及多层写入开关继续生效。
