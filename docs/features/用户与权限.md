## 1. 功能说明

管理本地账号、可用业务功能和ERP操作员映射。入口在设置中的用户管理、功能开关及当前账号菜单。

## 2. 已支持功能

- 用户搜索/状态筛选、新增、编辑、启停、解锁、重置凭据及会话撤销。
- 管理员标志、ERP操作员映射、分组折叠功能权限和适用业务的出入库类别范围。
- 全局功能开关、账号漫游偏好重置和用户管理操作记录。
- 管理员直接进入管理功能；普通账号可在服务端验证后获得短时管理权限。

## 3. 操作流程

进入用户管理 → 搜索或新增账号 → 设置账号、ERP映射和适用权限 → 保存 → 用目标账号重新核对功能入口与服务端操作权限。

## 4. 规则与限制

- “默认”表示继承：管理员默认继承启用功能，普通用户需明确允许；明确禁止会阻止对应功能。全局关闭也不能靠个人允许绕过。
- 页面隐藏只是显示规则，服务端仍校验权限；短时管理授权不自动增加业务功能权限。
- 出入库类别范围与业务方向要一致，调拨/盘点等按各自合同处理，不能套用所有模块统一方向。
- 当前会话保存在API进程，部署/回收或切换接口后需要重新登录；本机令牌按环境/API地址隔离。当前H5使用888开发账号，账号和ERP映射按实际服务器数据库区分，本轮没有复制或重置用户。
- 开发用户同步生产有历史记录，不代表数据同步页面的“用户信息”已经开放，也不是持续自动双向同步。
- 不在功能档案保存真实登录密码、管理密码或任何API Key。
