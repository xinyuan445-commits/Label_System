## 1. 功能说明

保存未上传单据，管理继续编辑、同步和ERP结果；区分本机保存、服务端同步、业务执行和审核阶段。

## 2. 已支持功能

- 标准IndexedDB草稿、多份记录、继续编辑及单据管理；会话/草稿/工作态/选单按环境及API地址隔离。
- 服务端草稿同步、状态事件、设备状态及保留策略；管理员查看范围由服务端权限决定。
- 已有业务的ERP单号和真实状态展示、失败与待核对恢复。
- 盘点确认原单立即落本机、旧记录幂等导入、同步原子修订保护。

## 3. 操作流程

确认/保存草稿 → 单据管理 → 查看同步状态或继续编辑 → 对已开放单据上传 → 根据真实业务结果处理审核、重试或核对。

## 4. 规则与限制

- 已保存本机、已同步和已上传ERP是不同状态；保存或同步不能冒充ERP成功。
- 草稿修改及管理有账号归属校验；删除/重置当前表单与服务端业务撤销不是同一件事，不能假定重置会冲销库存。
- 旧同步响应不能覆盖新数量；有处理中的保存/查询/完成时应阻止误操作。
- ERP结果未知先核对；ERP已成功但同步未完成恢复原任务，避免重复新增。
- 本机草稿不代表全部功能支持离线扫码；盘点已加载页面续扫规则见盘点档案。
- 盘点888按服务端能力开放上传保存未审核，生产008仍关闭；业务锁、过期、ERP映射、权限及写入门禁不能由本机状态绕过。真实首张保存由用户验收。
