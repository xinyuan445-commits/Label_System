## 1. 功能说明

按现有单据格式进行有原单或无原单盘点，保存明确盘点量并联网复核。不提供独立采集任务页。

## 2. 已支持功能

| 能力 | 当前行为 |
| --- | --- |
| 有原单 | 单张未审核原单；按单号/日期查找，无合并模式；完整表头、明细、行ID和指纹确认后立即存本机草稿 |
| 无原单 | 选择日期/仓库直接扫码制单，保存真实账套绑定，不伪造原单 |
| 仓库 | 有原单锁定，需重置清空后更换；无原单已扫码后同样锁定，避免跨仓串单 |
| 盈亏类别 | 可改选；有原单先带入原值，空值或无原单默认盘盈入库107、盘亏出库207 |
| 是否盘货位 | 只读；有原单取原单状态，无原单选仓库后取真实货位管理标志；不按货位列表是否为空猜测 |
| 数量与去重 | 首次为空，0需明确确认；重复完整Code警示拒绝，不累加、不覆盖 |
| 保存与离线 | 标准本机草稿、既有同步/继续编辑；已加载有效会话页面可断网续扫 |
| 在线完成 | 有原单复核源指纹/标签，无原单批量复核仓库及标签；保存成功后进入单据管理 |

## 3. 操作流程

可选原单 → 确认表头和是否盘货位 → 下一步扫码 → 输入并确认盘点量 → 完成做单保存草稿 → 单据管理查看或继续编辑。当前上传按钮禁用；“完成做单”不表示U8已写入。

## 4. 规则与限制

- 已有标签实时资料来自旧三表；打印数量不作余额或实盘默认值，未扫不当盘0。
- 单单最多1000个唯一完整Code；原单最多5000行，查询超出列表范围需缩小条件。
- 盘货位时标签须有货位并按货位匹配；不盘货位时按仓库维度匹配，仍保留标签最新位置。
- 原单与仓库货位管理标志分开读取；未知/失败不能默认否。旧原单草稿缺状态时重选同一原单，已盘数量保留。
- 负余额、旧表异常、仓库/单位不符、原单重复候选或自由项/辅计量不明确不能默认通过。
- 无原单完成前前后复核仓库配置，变化需重置后重试；快速切仓的旧响应不能覆盖新仓库状态。
- 新无原单先联网取得账套和仓库状态；只支持已加载页面续扫，无网冷启动未实现。离线记录后续必须实时复核。
- 原单完整快照不是全仓标签离线包；扫码汇总不等于完整应盘范围或U8整行最终实盘。
- 托盘不在本阶段范围；ERP新增/回填、审核生效与三表差异闭环未开放。
