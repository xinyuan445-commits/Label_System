## 1. 功能说明

按条件查询U8单据及状态，查看明细并执行审核或弃审；制单后的自动审核与手工审核分阶段处理。

## 2. 已支持功能

- 共用单据查询、明细、审核和弃审确认页，按类型分发。
- 材料出库新增后自动/手工审核、弃审及阶段恢复。
- 调拨关联其他出入库单的联动审核/弃审规则。

## 3. 操作流程

选择对应审核功能 → 查询单号/日期/状态 → 核对目标单与明细 → 确认审核或弃审 → 查看真实结果；失败按当前阶段处理，不重做已成功新增。

## 4. 规则与限制

- 权限、单据状态、ERP映射及写入开关必须服务端校验；界面可见或接口能力不代表允许执行。
- 调拨必须考虑关联单结果，不能只改主单显示状态；结果未知须核对。
- 审核/弃审不据按钮自动新增或冲销旧三表数量流水，数量变化与原业务事件分开。
- 盘点888仅开放上传保存未审核，原生审核接口不代表标签差异闭环完成；888业务审核/弃审仍拦截，不能把保存成功认定为库存已生效。生产008上传仍关闭。
- 不进行离线审核；其他类型没有完整证据时不得写“审核/弃审已验收”。

## 5. 未完成与后续

补齐采购/销售/委外及008各类现场证据；盘点真实回填、差异生效和弃审影响需独立验证后开放对应闭环。
