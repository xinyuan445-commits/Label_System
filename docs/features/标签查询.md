## 1. 功能说明

通过扫码或输入条码查看标签身份、当前数量、仓库/货位与状态。入口为标签查询。

## 2. 已支持功能

- 产品标签查询、料号/描述、批次、单位、余额和位置显示。
- 旧三表实时查询及本地标签镜像刷新。
- 仅查询产品标签；本地托盘回退及托内标签展示已移除。

## 3. 操作流程

进入查询 → 扫码或输入完整Code → 查看结果或异常 → 返回。查询结果不是制单授权，真实提交前必须重新复核。

## 4. 规则与限制

- 当前余额取同一完整Code汇总，当前属性/位置取最新有效流水；不能拆Code中的打印量当当前数量。
- 负余额、重复/缺失Goods、无效JSON或身份冲突进入待核对，不能随意选一条继续制单。
- 查询不会创建U8业务单或改变库存数量，但可以建立/刷新本地镜像；不能描述成完全不写本地数据库。
- 此页依赖在线查询，没有完整离线标签查询包；托盘路径已移除。

## 5. 未完成与后续

全量余额/位置对账、集中异常处理工具及旧表退出仍未完成；新设备物理扫码按设备分别验收。
