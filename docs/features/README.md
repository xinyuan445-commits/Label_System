## 2. 怎么看状态

- **代码实现**：源码里实际有对应行为；页面或接口存在不代表业务闭环已完成。
- **已部署**：有程序发布记录；入口仍受全局开关、账号权限、账套与写入门禁约束。
- **已验收**：必须写具体环境、场景、设备和证据；888通过不能替代008，自动测试/健康检查不能替代真实单据或实机。
- **未完成 / 暂缓**：直接写缺项，不以按钮改名、共用程序升级或数据结构存在冒充完成。

环境及版本统一引用[项目当前状态](../PROJECT_STATUS.md)，功能文件只记录该功能专属的历史版本/提交和发布证据。本次没有重新检查在线服务、数据库记录或设备。

## 5. 后续维护要求

1. 改功能前读对应档案；新增功能先建档并加进本索引。
2. 修改时同步已支持项、限制和未完项；业务规则/页面/接口/结构有变化时再更新对应专属文档。
3. 代码测试、发布和实机验收分别更新状态，附实际证据。仅整理文档不要新增软件版本或虚构验收。
4. 不保存密码、服务器凭据、API Key等秘密；不为整理档案重做真实业务或清除数据。
5. 本目录不新增定时任务、审批流程或独立记录平台，沿用本地Git变更历史；未经用户明确通知不推送GitHub。
