## 1. 功能说明

提供H5登录、地址配置和Android设备能力桥接；程序主体业务仍由H5与服务端承担。

## 2. 已支持功能

- 统一登录、会话恢复、退出；可选记住本机账号密码。
- 地址设置、扫码事件、系统返回交接、扫码/声音测试、提示音/语音反馈选择。
- 品牌图标与启动衔接动画、安全区处理、已加载盘点页离线保护。
- CT58C为主要支持基线；PX101A有既有安装和桥验证记录。

## 3. 操作流程

根目录启动脚本开启H5 → PDA配置实际网页地址 → 登录 → 进入功能。设备扫码/返回/声音由桥接收，业务是否成功由H5和服务端判断后反馈。

## 4. 规则与限制

- 现有H5端口为5175，实际IP和来源以项目状态为准；修改客户端地址还要核对服务端CORS，development名称不决定ERP账套。
- 记住密码只在用户勾选且完整登录成功后保存于当前设备、按环境/API地址隔离；不是账号漫游或加密保险箱。取消勾选清除，不将凭据写入仓库/日志。
- API进程会话在部署/回收后失效，需要重新登录；缓存登录态不能绕过服务端权限。
- 离线仅支持已加载且会话有效的盘点页面续扫，不等于无网冷启动、所有单据离线扫码或离线写ERP。
- APK更新需要覆盖安装，H5发布不自动替换APK；其他品牌设备不得仅因能打开页面就视为物理扫码兼容通过。
- 用户可选择关闭声音，不能把自动测试通过表述成所有设备都已听到警示声。
