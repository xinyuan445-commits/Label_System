## 1. 功能说明

将当前账套基础资料缓存到标签系统，供选择和搜索使用。入口为设置 → 数据同步。

## 2. 已支持功能

| 项目 | 当前情况 |
| --- | --- |
| 出入库类别、仓位、部门 | 已接入，显示条数及最近成功状态 |
| 物料档案 | 已接入，只读取未停用物料，搜索使用当前账套本地缓存 |
| 单据基础档案 | 已接入采购/销售类型、币种等共用资料 |
| 用户信息 | 页面项未开放，不是已完成的同步任务 |
| 草稿保留策略和设备状态 | 页面已有管理入口，详见草稿档案 |

## 3. 操作流程

进入数据同步 → 勾选已开放项目 → 立即同步 → 分项查看条数、时间及错误。首次使用依赖缓存的物料选择前，应先完成对应档案同步。

## 4. 规则与限制

- 来源按服务器真实账套/数据库，不按H5的development名称推断888。
- 物料条件为U8 Inventory.dEDate IS NULL且料号有效；不把停用物料全量带回。
- 同步读取U8并更新本地缓存，不据此创建U8业务单据或变更标签库存。失败时保留最后成功的资料。
- 缓存不是标签实时余额/位置的权威来源；无标签退料上传仍需实时复核。
- 盘点是否盘货位使用专用实时仓库接口，不按仓位缓存里有没有货位推断。
- 历史开发用户迁移不等于“用户信息”同步已开放；同步权限和管理入口仍由服务端校验。

## 5. 未完成与后续

用户信息等未接入项目继续单独安排；不要仅把禁用项目改成可点。基础档案结构变化须同步维护合同和迁移，不能改写已执行迁移。
