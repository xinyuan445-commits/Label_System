## 1. 功能说明

为业务产生的标签首打、补打并管理模板和任务。实际打印应用在New_Label_Print_System项目维护，本档案提供跨系统能力和限制索引。

## 2. 已支持功能

- 标签规则维护、当前规则选择、正式取号，模板正式发布及停启。
- 首打、原码补打、PDF输出、签名回执和原任务恢复。
- 首打唯一旧三表初始登记，防止补打或重试重复增加数量。
- 独立网页和打印助手在使用电脑本地运行，开发来源固定为159的9891/888。

## 3. 操作流程

在业务中产生待打印目标 → 进入独立标签打印程序 → 确认目标/模板/数量 → 实际首打时分配正式Code → 输出并处理回执/登记 → 贴标再扫码。补打复用既有Code和纸面快照，不当作新库存。

## 4. 规则与限制

- 制单和预览不生成正式Code；已有退料/部分移动目标的本地库存不能在打印时重复增加。
- PRINT/REPRINT打印本身本地数量变化为0；目标首次旧表正登记使用唯一事件，补打不重复正登记。
- 发送或回执结果不明时按原任务恢复，不能随意新建Code或再次首打。
- 888/PDF通过不等于实体机走纸、纸面质量及扫码通过；生产008的打印迁移/配置/验收尚未完成。
- H5不承载独立打印工作流；不能因共用API程序集包含路由就认定生产打印可用。

## 5. 未完成与后续

完成实际标签机驱动、走纸、纸面扫码、异常恢复现场矩阵，再安排008迁移和受控发布；详情在独立打印项目维护，避免复制两份模板/驱动设计。
