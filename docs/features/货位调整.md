## 1. 功能说明

处理同仓库内产品标签货位变更，与跨仓调拨区分。来源和目标位置按明细处理。

## 2. 已支持功能

| 能力 | 实现情况 | 边界 |
| --- | --- | --- |
| 扫码带出来源位置 | 已实现 | 实时标签状态，不由表头覆盖 |
| 明细目标货位、按仓库拆单 | 已实现 | 每条目标货位需属于当前仓库 |
| 全量调整 | 已实现 | 原Code保留，位置更新 |
| 独立标签部分调整 | 已实现 | 来源保留余量，目标无Code待打印 |
| U8及旧三表来源事件 | 已接入 | 全量零流水、部分来源负流水，目标首打后登记 |

## 3. 操作流程

扫码 → 查看来源仓库/货位 → 选择目标货位并确认数量 → 完成做单 → 单据管理上传及按策略审核 → 部分调整目标另行首打贴标后使用。

## 4. 规则与限制

- 目标货位须属于标签当前仓库且不同于来源货位；不能把货位调整作为跨仓调拨。
- 来源仓库和货位是库存身份，不允许随意编辑；当前名称优先按档案中的编码显示。
- 移动数量不能超过实时余额。部分数量按独立产品标签处理，托盘功能已移除。
- 无Code待打印标签不能直接扫描；目标正流水在正式首打登记，不能制单时伪造目标码。
- 上传前复核旧三表最新流水、余额、位置；结果不明或旧表同步失败按原任务处理，不重建ERP单。
- 已开发不等于最新PDA、实体打印、再次扫码组合已验收；不支持离线写ERP。
