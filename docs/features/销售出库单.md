2026-11-08复核、部署及实测。开发888运行 API 0.13.2、Gateway 0.12.2 和迁移021。蓝字无原单保存、审核、旧三表扣量和失败恢复已实测。关联发货单保存、已出量回写、剩余量查询、旧三表扣量、手工审核及弃审已实测。见[发布记录](../DEPLOYMENT_2026-11-08_SALES_OUTBOUND.md)。

## 功能与规则

| 能力 | 当前行为 | 验收边界 |
| --- | --- | --- |
| 选择原单 | 共用选单支持发货单和销售订单。发货可出量为 iQuantity 减 fOutQuantity，已保存的关联出库会占用余量 | 888已核对关联保存回写、发货剩余量及已出完拦截 |
| 写前复核 | 按原单行累计复核可出量、客户及明细身份。实时校验旧表流水ID、余额、料批、单位和位置 | 过期流水有自动测试 |
| 扣量 | ERP保存后，蓝字按稳定事件键向旧三表追加负数量，刷新本地标签镜像。Goods保留标签所在仓库和货位 | 蓝字有发货原单及无原单实写通过，红字事件方向有自动测试 |
| 恢复 | ERP已保存但追溯失败时，重交原请求继续原任务。相同请求返回同一结果，改内容复用请求号拒绝 | 888定向故障、恢复和重放实测通过 |

选择原单或录入表头 → 扫码并确认数量 → 保存草稿 → 上传 → 按需要审核。同一完整标签码在一次请求中只允许一条出库明细。沿用功能权限、仓库数据范围和账套写入门禁。
