## 1. 功能说明

在仓库间调拨产品标签数量。使用共用制单页，来源位置取标签实时状态，目标位置按明细填写。

## 2. 已支持功能

| 能力 | 实现情况 | 边界 |
| --- | --- | --- |
| 调出/调入部门 | 已实现 | 表头分别设置，不共用一个部门值 |
| 来源和目标位置 | 已实现 | 来源只读，目标按明细选择；可按业务分组拆单 |
| 全量移动 | 已实现 | 使用原Code，最新位置变为目标 |
| 独立产品标签部分移动 | 已实现 | 来源保留余量，目标生成无Code待打印标签 |
| 关联单联动审核/弃审 | 已实现，有888记录 | 必须关注调拨关联其他出入库单的真实结果 |
| 旧三表同步和恢复 | 已接入 | 全量与部分采用不同流水规则 |

## 3. 操作流程

填写表头部门/类别 → 扫码 → 查看来源并确认调拨量和目标位置 → 完成做单 → 单据管理上传 → 联动审核。部分移动的目标标签另到打印程序首打、贴标后再扫码。

## 4. 规则与限制

- 来源仓库/货位不能用表头覆盖或手工伪造；目标货位必须属于目标仓库，调出与调入仓库不能相同。
- 部分移动按独立产品标签处理，原装托关系不再参与业务；托盘功能已移除。
- 全量移动向原Code追加零数量并更新最新位置；部分移动扣减原Code且保留来源位置，目标首打后才登记新Code的正数量。
- 当前名称优先按仓库/货位编码匹配档案，不能用旧名称快照替代真实编码。
- 关联审核有失败或结果不明时不能仅凭主单状态判断全部完成；同步失败只恢复原任务，不再新建调拨单。
- 不承诺离线写入或所有008现场场景已经验收。
