# 标签管理系统 H5

## 本地开发

```powershell
npm install
npm run dev
```

默认监听 `0.0.0.0:5173`。本机可访问 `http://localhost:5173`，同一局域网的 PDA 使用电脑的局域网 IP。development 环境使用 `admin/admin` 登录。

当前 CT58C 测试地址为 `http://172.16.10.45:5173/`。电脑 IP 变化后，在登录页进入“设置 > 地址设置”修改开发地址。

运行时配置位于 `public/runtime-config.json`。test 和 production 必须关闭 `enableMockLogin`、`enableMockScanner` 和 `enableVConsole`。

```powershell
npm run typecheck
npm run build
```

## 当前页面

```text
/                    业务中心
/favorites           常用功能管理
/functions           全部功能
/work/:code           业务功能页
/work/:code/source    业务源单选择
/work/:code/documents 业务单据管理
/work/:code/switches  业务开关设置
/login                登录
/settings             设置中心
/settings/address     地址设置
/settings/features    功能开关
/settings/data-sync   数据同步
/settings/users       用户管理
/settings/scanner     扫码测试
/settings/sound       扫码提示音测试
```

业务中心只显示常用功能和“全部功能”入口。常用功能最多选择 6 个，当前按用户名保存在浏览器 `localStorage`；清除应用数据、卸载应用或更换设备后不会保留。以后如需多设备同步，应迁移到后端用户偏好接口。

设置中心的“功能开关”当前统一控制所有账号可见的业务功能，切换单项或整组后立即保存，不设置额外保存按钮。关闭后，对应入口会从全部功能、常用功能和常用功能管理中隐藏，直接访问业务路由也会返回业务中心。正式功能目录及全局开关保存在业务数据库 `system_function` 表，并由 API 返回；当前浏览器 `localStorage`（键名 `label-system:feature-visibility:global:v1`）只用于后端接入前模拟交互，不作为正式配置来源。后续增加用户级权限覆盖，功能可见性不能代替后端权限校验。

扫码提示音选择后立即保存并播放测试音，不设置额外保存按钮。关闭模式会立即保存静音配置，不播放声音。

设置中心的“数据同步”当前提供用户信息、出入类别和仓位信息三个复选项，默认全部选中，点击“立即同步”前必须至少选择一项。后端接口尚未接入，当前按钮只提示接口待接入，不产生或修改任何正式数据。

“用户管理”与“数据同步”为设置中心的两个独立同级入口。用户管理当前仅建立独立页面，用户列表、账号维护和权限配置等待后端用户体系确定后接入。

设置页底部显示 `H5 版本 · APK 版本`。H5 版本在构建时从 `web/package.json` 注入；APK 版本由原生壳配置消息返回。旧版原生壳未返回版本字段时暂用当前兼容版本显示，下一次 APK 发布后改为设备实际安装版本。

全部功能当前包含采购管理、销售管理、库存管理、审核管理和信息查询。采购到货、委外到货、采购入库、发货单、销售出库单、材料出库单、调拨单、货位调整和盘点单已经接入统一 H5 做单模板；九类审核入口已经接入统一审核页面，标签查询暂为占位页面。

非审核类业务单据使用两步流程：第一步填写表头，第二步扫描标签并维护明细。表头字段、源单类型、明细标题和数量名称按单据类型配置，必填项使用红色星号标识。材料出库仓库不在表头手工填写，后端接入后从标签当前位置取得并按仓库拆分 U8 单据。

存在源单关系的业务可进入独立选单页，按日期范围或源单号查询。当前支持 PDA 扫码、浏览器手动添加、数量编辑、明细删除、合计和本地单据。

业务单据底部均可进入“单据管理”。表头页默认由“单据管理”和“下一步”平分整行；填写内容后，中间显示“重置”按钮。扫码页面由用户点击“完成做单”后才保存到未上传列表，不自动暂存；扫码内容发生新增、删除或修改后离开页面，会让用户选择完成、放弃或继续操作。从未上传列表打开单据但未作任何修改时，返回不提示。

扫码页面右上角可进入“开关设置”。第一组按当前单据分别设置“扫托包含托盘”“完成自动上传”和“上传自动审核”，后两项默认关闭；每个开关旁的“全局”按钮只同步该项，并从顶部短暂提示“已全局同步”。“原因必填”放在全局“操作设置”中，“需要审核”不在本页面提供。托盘规则放在可折叠的全局“托盘设置”中。当前开发阶段配置保存在浏览器 `localStorage`，接入后端后迁移到系统配置接口。

本地单据可保存多份，按当前业务分开显示，并通过“未上传 / 已上传”切换；点击未上传记录直接继续编辑，记录上的上传和删除按钮用于对应操作，已上传单据支持查看。当前后端尚未接入，“上传”只提示接口待接入，不会将本地单据标记为已上传。完成的本地单据保存在浏览器 `localStorage`；进入选单页或单据管理时，当前未完成内容只通过 `sessionStorage` 临时传递，不会出现在未上传列表。

后续新增的非审核类业务单据继续沿用当前模板，各单据只调整表头字段、源单类型、扫码规则和提交规则。审核功能不套用此模板，页面方案后续单独确定。

审核页面使用“待审核 / 已审核”列表、日期和单号查询、单据详情、ERP 明细及标签影响展示。审核和弃审均需二次确认；全局“原因必填”开启后，确认时必须填写原因。当前单据和审核结果均为前端模拟数据，状态保存在浏览器 `localStorage`，不会调用 U8、写入业务数据库或产生真实标签流水。接入后端后，列表、详情和操作结果改由接口提供。

业务流程不依赖浏览器历史逐级返回。源单选择、开关设置和单据管理固定返回当前单据；完成做单后以替换方式进入单据管理，不再返回已完成的扫码页。业务单据从常用功能进入时返回业务中心，从全部功能进入时返回全部功能；全部功能自身返回业务中心。PDA 系统返回键遵循同一规则；扫码内容发生变化时，返回前仍需选择完成、放弃或继续操作。

U8 和标签业务后端尚未接入。源单页输入单号后仅生成可选的前端结果，按日期查询完整列表仍提示接口待接入；提交只执行前端必填校验，不会生成真实单据。

## 文档维护

以下变化需要同步更新本文件：

- 新增、删除或调整页面和路由。
- 启动、构建、部署或运行环境发生变化。
- 浏览器缓存、本地草稿、登录或扫码行为发生变化。
- 后端接口从模拟、待接入变为可用，或其限制发生变化。

仅颜色、间距、图标等不改变使用方式的样式调整，无需逐次记录。业务规则和数据库决策维护在根目录 `BUSINESS_LOGIC.md`、`ARCHITECTURE.md` 及 `docs/database/`，不在本文件重复展开。
