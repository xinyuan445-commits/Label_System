# 标签管理系统 H5

## 本地开发

```powershell
npm install
npm run dev
```

默认监听 `0.0.0.0:5173`。本机可访问 `http://localhost:5173`，同一局域网的 PDA 使用电脑的局域网 IP。development 登录已经接入 `http://172.16.1.159:9890` 的 Business API，不再由 H5 本地校验。

当前开发地址固定为 `http://172.16.10.45:5173/`。电脑 IP 或端口变化后，在登录页进入“设置 > 地址设置”修改开发地址，并同步维护 Business API 的精确 CORS 来源。

运行时配置位于 `public/runtime-config.json`。development 的登录、设置、源单、标签/托盘和九类单据上传均调用 `http://172.16.1.159:9890` 的 Business API；本地模拟登录、模拟源单和模拟业务上传已关闭。`enableMockScanner` 只模拟扫码输入事件，不生成标签数据。当前 H5 版本为 `0.2.0-dev.60`。

```powershell
npm run typecheck
npm run build
```

## 登录和会话

H5 通过统一请求层调用 `/api/v1/auth/login`、`/api/v1/auth/me` 和 `/api/v1/auth/logout`。development 管理员和 Business API 中启用的本地密码账号共用同一登录页。登录成功后按环境保存服务端用户、角色、Bearer Token 和过期时间；启动时先使用有效缓存会话渲染页面，再在后台调用 `/auth/me` 校验，避免服务短暂重启时白屏等待。服务端返回 `401` 时清除本地状态并回到登录页；网络不可用但缓存会话仍在有效期内时暂时保留登录状态，恢复网络后的接口请求继续由服务端校验。登录页按环境记住最后一次成功登录的账号，主动退出后仍保留账号；密码不缓存、不预填。

当前 development 会话保存在 Business API 进程内，API 重启后需要重新登录。IIS 应用池已关闭空闲停止并设为始终运行，避免长时间未请求后丢失进程内会话；部署、手工回收或服务器重启后仍需重新登录。H5 按登录响应的剩余秒数计算本机会话有效期，避免 PDA 时钟偏差；WebView 持久存储不可用时使用当前进程内存会话，关闭 APK 后需要重新登录。请求编号对不支持 `crypto.randomUUID()` 的旧版 Android WebView 使用兼容生成方式。CT58C 的 5173、5174 来源已加入 development API 的精确 CORS 允许列表；开发电脑 IP 变化后，除修改 H5 地址外还要同步更新 API 允许来源。

统一请求超时覆盖建立连接、等待响应和读取响应体，默认 15 秒，基础资料同步为 45 秒，大单据预提交为 120 秒。即使旧版 WebView 未能及时中断底层连接，页面也会退出加载状态并允许再次操作。

单据管理把服务端明确失败的单据放回“未提交”，卡片持续显示错误码和错误内容，按钮显示“重新上传”。用户修正数据后可重新提交并生成新的请求号；结果未知的单据仍进入“待核对”，只允许刷新核对，避免重复写入 ERP。

全部 H5 页头在触屏窄屏下预留 Android 顶部状态栏安全区，并优先使用设备上报的 `safe-area-inset-top`；业务中心账号名称过长时自动省略，避免与标题或系统状态图标重叠。

## 当前页面

```text
/                    业务中心
/favorites           常用功能管理
/functions           全部功能
/work/:code           业务功能页
/work/:code/source    业务源单选择
/work/:code/source-details 源单明细
/work/:code/documents 业务单据管理
/work/:code/switches  业务开关设置
/work/:code/document-settings 单据字段设置
/login                登录
/settings             设置中心
/settings/address     地址设置
/settings/label-code-rules 标签编码规则（管理员）
/settings/features    功能开关
/settings/data-sync   数据同步
/settings/users       用户管理
/settings/scanner     扫码测试
/settings/sound       扫码反馈
```

业务中心支持简约和详细模式。简约模式显示常用功能快捷入口和“全部功能”入口；详细模式按业务分组直接列出当前用户可用的全部功能。现有用户默认详细模式，切换入口在右上角用户下拉菜单。常用功能最多选择 6 个，常用功能和显示模式分别保存在 Business API 用户漫游偏好 `workspace.favorites`、`workspace.homeMode`，浏览器 `localStorage` 仅作当前设备缓存；同一账号更换设备后会读取服务端配置。

登录后的用户下拉菜单提供“设置”和“退出登录”。登录页仍保留设置入口，用于未登录时调整访问地址；功能开关、数据同步和用户管理必须登录后访问。

设置中心的“功能开关”统一控制所有账号可见的业务功能。登录后 H5 调用 `/api/v1/functions` 缓存当前账号的有效功能，并与全局开关共同决定首页、全部功能和业务路由；管理员默认继承已启用功能，普通用户只显示明确允许的功能。服务端仍会在审核和预提交接口再次校验权限，前端隐藏入口不作为授权依据。

“扫码反馈”可选择提示音、语音播报或关闭。提示音模式在成功时播放一声短音，失败时连续播放三声短音；语音模式使用中文女声播报“成功”和“错误”。标签真正加入扫码明细后反馈成功，重复、未找到、物料不匹配、数量或确认校验失败反馈失败；用户主动取消不反馈。选择后立即保存，页面可分别试听成功和错误。旧版短音、柔和或双音配置升级后归入提示音，旧版关闭继续保持静音。

设置中心的“数据同步”已接入出入库类别、仓位信息和部门信息。点击“立即同步”后由 Business API 读取 U8 完整快照并缓存到标签数据库，页面分别显示条数和最近成功时间；用户信息仍为待接入。同步只读取 U8，不创建标签、业务操作或 U8 单据。

设置中心的“标签编码规则”仅管理员可见。管理员可以组合固定内容、自定义分隔符、业务字段、日期、流水和校验位，选择常用一维码、QR 和常用二维载体，先预览再保存草稿并启用。已启用版本不原位修改，后续调整生成新版本；停止生成后历史标签仍可解析。H5 在登录和会话恢复后后台刷新按环境保存的规则目录，刷新失败继续保留上次缓存；当前扫码仍以 Business API 解析为准，尚未启用离线解析，也不会生成正式标签或消耗流水。

规则对象可选择“产品/托盘通用”；解析后再由库存数据确定实际对象。字段可设置限定值，数量可指定固定小数位。development 当前启用 `INV008_STANDARD` V1：`008|料号|批号|两位小数数量|10 位标签唯一值`。

制单页面的出入库类别、部门、仓库和货位字段使用服务端缓存选项，均可按编号或名称模糊搜索。类别按单据入库/出库方向、末级状态和当前用户在该做单功能的类别范围过滤；部门、仓库和货位不做用户范围限制，货位按当前仓库过滤。旧草稿中的原编码若已停用或已超出范围仍可查看，但预提交时必须重新选择。

“功能开关”“数据同步”和“用户管理”属于管理入口。管理员直接进入；普通用户进入时输入管理密码，由 Business API 验证后给当前会话 10 分钟管理权限。H5 不保存管理密码，短时管理权限也不会增加业务功能。用户管理支持搜索、状态筛选、新增、编辑、启停、重置密码、ERP 操作员映射、分组功能权限、各做单功能的出入库类别范围、账号解锁、会话撤销、漫游数据重置和操作记录。

本地密码不要求最低长度、大小写、数字或特殊字符组合，单字符密码可用；页面只要求非空并保留 128 字符技术上限。

完成做单后的草稿保存在 PDA IndexedDB，并在停止操作约 3 秒后同步到 Business API；断网时继续保存在本机，恢复网络或重新进入应用后自动补传。普通用户只查看自己的草稿，管理员角色可查看全部已同步草稿；短时管理密码不开放其他用户草稿。完全离线时管理员只能看到该 PDA 最后一次成功上报的状态。

草稿同步状态分为待同步、同步中、已同步、同步失败和删除待同步；服务器发出的删除标记收到确认后才移除本地副本。单据管理右上角的“删除”只处理当前设备记录：可逐条选择或全选，删除 IndexedDB 副本并在本机隐藏对应服务器记录，不删除服务器草稿、业务操作或 ERP 单据，其他设备仍可查看。服务端正文使用带 `schemaVersion` 的 JSON，只保留最新版本；创建、状态变化和删除保留轻量事件，不保存每次内容修改历史。数据同步页可设置活跃草稿和已结束记录按天或永久保留，管理员同时可查看各 PDA 最近在线时间及草稿、待同步和失败数量。

应用用户显示名只用于界面和本地业务快照。真实 U8 制单人由服务端用户表中的 ERP 映射决定，H5 不提交可受信任的 ERP 制单人；未配置映射时不能执行真实 U8 写入。地址、扫码器、声音等设备设置不随用户漫游。

设置页底部显示 `H5 版本 · APK 版本`。H5 版本在构建时从 `web/package.json` 注入；APK 版本由原生壳配置消息返回。旧版原生壳未返回版本字段时暂用当前兼容版本显示，下一次 APK 发布后改为设备实际安装版本。

全部功能当前包含采购管理、销售管理、库存管理、审核管理和信息查询。采购到货、委外到货、采购入库、发货单、销售出库单、材料出库单、调拨单、货位调整和盘点单已经接入统一 H5 做单模板；九类审核入口读取真实 U8 单据，标签查询读取业务库现有标签和托盘。

非审核类业务单据使用两步流程：第一步填写表头，第二步扫描标签并维护明细。表头字段、源单类型、明细标题和数量名称按单据类型配置，必填项使用红色星号标识。所有单据的源单均为可选，不选源单也可以进入扫码、完成做单和预提交；材料出库需要关联时只选择生产订单，仓库不在表头手工填写。

材料出库选择生产订单后，出库类别自动固定为 `202` 并禁止修改；清除源单后恢复为可选择状态。旧草稿重新打开时，只要仍带有生产订单来源，也按 `202` 规范化。

存在源单关系的业务可进入独立选单页，按订单日期范围、单号或产品查询已审核、未关闭记录，也可跳过选单直接扫码。默认“合并显示”按生产订单展示，选中后重新读取整张订单的全部有效明细带入扫码；“明细显示”允许多选，也允许跨生产工单选择。未关闭根据 U8 关闭日期、关闭时间判断，不依赖订单状态。选择源单后，扫码料号、来源数量和并发占用按来源明细校验，料号比较不区分大小写；未选源单时不生成来源关联。材料出库选择生产订单后携带完整表头和子件分配，按“生产订单内部 ID + 当前仓库”拆组；未选源单时只按标签实际仓库拆组。完成做单始终至少需要一条扫码明细。当前支持 PDA 扫码、浏览器手动添加、数量编辑、明细删除、合计和本地单据。

选单页的全部参数默认折叠，只显示“选单类型 · 合并/明细”和日期或关键字预览；点击预览展开修改，展开后选单类型与“合并 / 明细”放在同一行，查询成功后自动折叠。

日期字段统一使用 H5 页面内日期面板，不调用 CT58C WebView 91 的原生日期弹窗。源单查询、单据日期和审核日期切换页面时会随组件正常关闭，避免原生弹窗导致容器进程崩溃。

业务单据底部均可进入“单据管理”。表头页默认由“单据管理”和“下一步”平分整行；填写内容后，中间显示“重置”按钮。扫码页面由用户点击“完成做单”后才保存到未上传列表，不自动暂存；扫码内容发生新增、删除或修改后离开页面，会让用户选择完成、放弃或继续操作。从未上传列表打开单据但未作任何修改时，返回不提示。

完成做单写入 IndexedDB 前会把 Vue 响应式草稿转换为普通 JSON，避免 WebView 无法结构化克隆 Proxy 导致保存失败；校验或保存失败会在操作栏上方持续显示原因，修正后可再次完成。

扫码页面选择了源单时，底部操作栏将“领料明细”或“源单明细”与“完成做单”放在同一行；顶部只保留“开关设置”。

填写表头页面右上角可进入独立“单据设置”，不与扫码页面的“开关设置”混放。九类制单的表头、表体字段都在该页面按基础、文本、数值和日期分类折叠，每项有“显示”和“必填”两个开关；必填会自动开启显示，关闭显示会取消必填。

表体基础字段统一包含标签码、对象类型、料号、物料名称、批号、计量单位、仓库、货位、可用量和当前业务数量，并按单据补充项目、行备注、目标仓库或目标货位。九类单据均按实际 U8 合同列出表头自定义项 1–16、表体自定义项 22–37；采购到货、委外到货、采购入库、发货单、销售出库、材料出库和调拨单另按合同数量列出长文本自定义项。发货单表体自定义项 36、37按文本字段展示，其余单据按实际日期类型展示。字段设置会直接控制表头和扫码明细的显示、输入控件及完成做单前的必填校验；填写值随本地草稿、设备漫游草稿和预提交请求保存。制单人与 U8 操作人继续取当前登录用户，不作为手工字段。

扫码页面右上角的“开关设置”继续只管理业务策略、操作设置和托盘设置。每种单据提供“扫码后自动添加到明细”：开启后把标签返回的料号、批号、单位、仓库、货位和数量直接形成扫码明细；关闭后逐条进入明细确认页，显示该单据已开启的表体字段并允许修改。扫托返回多条标签时依次确认，全部确认后一次加入；取消则不加入本次扫描结果。即使开启自动添加，只要存在无法自动取得的必填表体字段，也会进入确认页。

扫码记录使用精简卡片，只显示料号、物料描述、批号、仓库、货位、单位、标签数量和已拣数量；点击卡片可重新编辑数量及允许填写的目标和扩展字段。标签码、料号、批号、库存单位、来源仓库和来源货位属于库存身份，只读显示，不能在制单页改写；上传时 Business API 仍读取最新库存记录复核。

材料出库选择生产订单后，新扫描标签的默认已拣数量为该料号尚未覆盖的剩余待领量与标签可用量中的较小值；同料前一标签已领 7、剩余 3 时，后一标签默认只带 3。仓库和货位选择器按编号或名称检索，选中后只显示名称；选择列表使用独立弹层，避免被 PDA 输入法遮挡。

扫码卡片始终显示“本标签使用”，表示当前单据实际使用这张标签的数量。有源材料出库另按料号显示“需拣数量”和当前单据同料标签自动汇总的“已拣数量”；编辑任一标签数量后汇总立即更新。已拣达到需拣且没有未分配数量时，卡片叠加“拣货完成”印章。

领料明细按子件需求显示 U8 的计划、已领、待领以及当前草稿的已拣数量。重新选择生产订单会重新读取 U8；待领为零的需求行显示“领料完成”。

领料明细同时显示“超领 数量”：上传前合并当前草稿分配到该需求行的超领量，上传后按 U8 已领超过计划的数量恢复。外部扫码记录按标签显示本标签实际超领量；“领料完成”和“超领”可同时出现。

当前上述进度和超领显示只完成材料出库。后续进入采购到货、采购入库、委外到货、发货单或销售出库原单测试时，先确认并接入各自的计划、ERP 已处理、待处理、本次已拣、完成和超量规则；红字业务另行确认数量方向。

材料出库开启“允许超领”后，已领完的源单物料仍可扫码，但不会自动使用整张标签数量；页面强制要求填写本次超领数量。同料只有一条候选子件需求时自动归属，存在多条候选需求时才选择产品和需求行。关闭超领时仍提示该物料已拣足。

取消超领归属弹窗只关闭选择界面，已确认数量的扫码记录继续保留并显示“待选超领归属”。点击该标记可继续选择；未完成归属时不能完成做单，主动删除扫码记录才会移除。

页面从 Business API 加载全局设置和当前单据设置，保存时携带行版本；“全局”会把策略项同步到各单据类型。“原因必填”位于操作设置，托盘规则位于托盘设置。浏览器只保留最近一次成功读取的缓存，服务端设置为准。`auto_add_scanned_detail` 与字段规则相同，属于单据公共配置，不属于个人漫游；扫码确认后的字段值继续进入本人草稿、漫游快照和预提交负载。

采购到货、委外到货、采购入库、发货单、销售出库和材料出库在源单下方使用“单据类型”下拉框选择蓝字或红字，默认蓝字。该下拉框由 H5 页面内弹层实现，不调用 Android 原生选择窗口，避免 CT58C 微信容器因系统资源异常退出。源单仍为可选，红字可参照源单，也可不选源单；选择值进入本地草稿和提交请求。development 已连接测试账套 888，红字必须按单据逐类验收。

材料出库选择红字后，无原单时在扫码框下按编号或名称查询物料；有原单时不显示查询框，直接在“退料明细”选择已领需求行。选择后进入退料编辑，填写退料数量、批号、仓库和货位，点击已添加的手工明细可再次修改。每条有源退料固定归属所选需求行，并按该行当前可退数量限制，不显示或使用蓝字的需拣、超领和拣货完成。上传成功后，单据详情显示系统生成的待打印标签 Code；实体二维码已经生成并贴附后点击“确认已贴标”，标签才变为可扫码状态。

已全部领用且状态为 `USED` 的产品标签仍可在红字材料出库中扫描。系统不会把当前零余额当作退料上限，扫码后固定进入明细编辑，用户输入退料数量并选择退料仓库、货位；上传成功后复用原标签并恢复可扫码状态。托盘、蓝字和其他单据不放开该状态。

九类单据共用的明细编辑页会在数值或文本输入获得焦点后，根据 PDA 可视区域自动滚动，避免数量等输入框被软键盘遮挡。

字段“显示/必填”属于单据级公共设置，保存在 Business API 的 `system_setting`，同一单据对所有用户生效；它不写入用户漫游偏好。只有管理员账号显示“单据设置”入口并可保存，普通用户输入管理密码也不能访问或修改。各用户填写的字段值属于单据草稿内容，按创建用户和设备同步漫游。

九类单据管理合并当前设备 IndexedDB、服务端草稿和真实业务组。明确失败且仍有完整草稿的单据只显示在“未提交”；草稿重试成功并改绑新业务组后，旧失败组仅保留服务端审计，不再重复显示在“已结束”。`NEEDS_RECONCILIATION` 等结果不明确记录只显示在“待核对”，没有此类记录时隐藏该页签。普通用户可在另一台设备下载自己的最新草稿继续处理，管理员可以查看其他员工草稿和业务状态，但不能以员工身份继续编辑。服务器软删除会先同步删除 PDA 本机副本，避免旧本地草稿再次上传；删除记录不在单据列表显示。

单据操作按钮统一显示“上传 ERP”。九类单据点击一次后由 Business API 在一个请求内完成校验、拆组、锁定和 ERP 执行，不再保留供用户二次操作的“待处理”。制单人缺失或写入前校验失败时，本机单据继续留在“未提交”，服务端不保留普通待处理组且不锁标签；成功直接进入“已结束”，成功提示、卡片和详情显示 ERP 返回的单据号，拆成多张时全部列出。只有 U8 调用结果不明确时显示“待核对”，禁止直接重做。development 已开放测试账套 888 的真实新增。

“上传自动审核”适用于自动上传和手工上传。服务端先完成 ERP 新增、单号回写和本地库存事务，再审核新增单据；审核明确失败时显示“待审核”并允许创建人继续审核，不重新新增 ERP 单据，结果未知时进入“待核对”。

明确 `FAILED` 的上传仍留在“未提交”，再次点击时生成新的 UUID 请求号并允许服务端草稿改绑；请求号不拼接原单据 ID，确保满足 Business API 最长 64 字符限制。一次请求已经发出但客户端只遇到超时或断网时，继续沿用本地 `uploadRequestId` 查询或重发同一请求，不能生成新号。`NEEDS_RECONCILIATION` 不提供重试。

数据同步增加“单据基础档案”，缓存采购类型、销售类型、币种和汇率。采购/委外到货选择采购类型，发货单选择销售类型；采购入库和销售出库同时选择业务类型与出入库类别；调拨、盘点分别选择两个方向的类别。

调拨和货位调整按整件处理，数量不可修改。扫描托盘会同时加入托盘自身和全部托内有效产品；删除其中任一项会移除整托。盘点数量允许为零或高于当前账面数量，预提交阶段只锁定对象，不修改库存。

采购、销售和委外单据提交前会按扫码料号把数量分配到所选 U8 来源行，跨多个同料来源行时按可用数量拆分；Business API 再次读取 U8 当前行并复核。六类源单搜索和整单明细已通过测试账套只读验证；委外到货单写入仍未验收。审核功能使用独立页面，不套用做单模板。

审核页面使用“待审核 / 已审核”列表、日期和单号查询、真实 U8 单据详情及明细。标签影响只显示业务库已有记录，当前没有记录时为空，不生成模拟标签。审核和弃审均需二次确认；全局“原因必填”开启后必须填写原因。development 的确认操作会真实调用测试账套 888。

源单选择、领料/源单明细、开关设置、单据字段设置和做单中打开的单据管理都作为当前单据的辅助页入栈；页面返回与 PDA 系统返回键均回到原做单页。直接打开辅助页时固定回到对应单据。登录、退出、完成做单、放弃做单以及完成后进入单据管理继续替换历史，不返回已失效或已完成的页面。业务单据从常用功能进入时返回业务中心，从全部功能进入时返回全部功能；扫码内容发生变化时，返回前仍需选择完成、放弃或继续操作。

九类制单的表头和扫码属于同一页面的两个步骤。进入扫码步骤后，顶部返回或 PDA 系统返回第一次只回到表头，保留表头和扫码明细；在表头再次返回才离开制单页，并继续执行原有未保存检查。

development 环境由 Business API 代理测试 U8 Gateway 的采购订单、采购到货、委外订单、销售订单、发货单、生产订单和子件查询，并从 `LabelSystem_Dev` 查询真实标签/托盘。H5 不持有 U8 Gateway 密钥，也不提供 `MOCK|...` 标签或模拟正式提交。没有正式标签数据时扫码查询会直接提示未找到标签。

## 文档维护

以下变化需要同步更新本文件：

- 新增、删除或调整页面和路由。
- 启动、构建、部署或运行环境发生变化。
- 浏览器缓存、本地草稿、登录或扫码行为发生变化。
- 后端接口从模拟、待接入变为可用，或其限制发生变化。

仅颜色、间距、图标等不改变使用方式的样式调整，无需逐次记录。业务规则和数据库决策维护在根目录 `BUSINESS_LOGIC.md`、`ARCHITECTURE.md` 及 `docs/database/`，不在本文件重复展开。
